# Changelog

All notable changes to this collection are documented in this file.

## [0.1.0] - 2026-09-23

### Added

- Initial release of `pathlyhq.pathly` `0.1.0`.
- Modules: `pathly_scenario`, `pathly_webhook`, `pathly_maintenance_window`,
  `pathly_sla_target`, `pathly_scenario_info`.
- Shared HTTP client with Bearer auth, idempotency keys, and Retry-After handling.
- English and French module documentation.
- Unit tests with 100% branch coverage on `module_utils` and module run logic.
